CNPJ, NF-e e Simples Nacional direto no seu assistente de IA.

O MCP Fiscal Brasil liga o Claude, o Cursor e outros assistentes compatíveis com MCP a 45 ferramentas fiscais brasileiras, de consulta de CNPJ e leitura de XML de NF-e a SPED, tabelas NCM/CFOP e simulação da Reforma Tributária. Gratuito, roda na sua máquina e não pede chave de API.

Ver instalação Ver no GitHub
$ uvx mcp-fiscal-brasil

Feito para quem vive o fiscal brasileiro

Em vez de abrir cinco portais para responder uma pergunta, você pergunta em português e o assistente chama a ferramenta certa.

Contadores

Confira CNPJ, CNAE e opção pelo Simples de um cliente, encontre o CFOP ou o NCM certo e corrija valores pela Selic ou pelo IPCA sem sair da conversa.

Escritórios contábeis

Faça triagem de carteiras de fornecedores em lote, leia XML de NF-e recebida, resuma arquivos SPED e simule a transição da Reforma Tributária para cada cliente.

Devs fiscais

Use o mesmo núcleo como servidor MCP, SDK Python, CLI (mcp-fiscal) ou API REST (mcp-fiscal-api) dentro do seu ERP ou automação.

Perguntas reais, ferramentas reais

Alguns pedidos que você pode fazer ao assistente e o que ele usa para responder.

Esse CNPJ é do Simples Nacional ou MEI? Desde quando?

Retorna a situação atual e as datas de opção e exclusão do Simples e do MEI.

consultar_simples_nacional · consultar_status_mei

Confira a nota em ~/Downloads/nota.xml. Está tudo certo com ela?

Lê o arquivo XML local (o caminho precisa estar acessível ao processo do servidor), confere o dígito da chave de acesso e os dados do emitente e lista os problemas encontrados. Também valida a assinatura digital e gera o DANFE em PDF.

validate_nfe_full · validar_assinatura_nfe · gerar_danfe

O que é o CFOP 6102 e qual a alíquota de ICMS de SP para BA?

Consulta as tabelas offline de CFOP e de alíquotas interestaduais de ICMS, que já vêm no pacote.

consultar_cfop · consultar_aliquota_icms

Como a carga tributária desta empresa muda entre 2026 e 2033 com IBS e CBS?

Simula ano a ano a transição da LC 214/2025, comparando o regime antigo com o novo.

simular_transicao_reforma_tributaria

Resuma este arquivo SPED Fiscal: período, empresa e inconsistências.

Identifica o tipo (EFD-ICMS/IPI, Contribuições, ECD ou ECF), extrai período e empresa e aponta inconsistências. Tudo processado localmente.

summarize_sped · listar_registros_sped

Vale mais a pena MEI, Simples, Lucro Presumido ou Lucro Real com faturamento de R$ 500 mil?

Compara os quatro regimes para o cenário informado (faturamento, setor e folha).

compare_tax_regimes

Instalação e primeiros passos

Requer Python 3.10 ou superior. O jeito mais simples é o uvx, do uv, que baixa e executa o pacote do PyPI num ambiente isolado. Nenhuma chave de API é necessária.

1. Teste no terminal

Se ainda não tem o uv, instale pelo comando oficial. No macOS e no Linux:

curl -LsSf https://astral.sh/uv/install.sh | sh

No Windows (PowerShell):

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Depois, rode o servidor:

uvx mcp-fiscal-brasil

Para sempre pegar a versão mais nova do PyPI: uvx mcp-fiscal-brasil@latest.

2. Claude Desktop

Edite ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) ou %APPDATA%\Claude\claude_desktop_config.json (Windows), salve e reinicie o app:

{
  "mcpServers": {
    "fiscal-brasil": {
      "command": "uvx",
      "args": ["mcp-fiscal-brasil"]
    }
  }
}

Cursor

Use o mesmo bloco mcpServers acima em .cursor/mcp.json, para valer só no projeto, ou em ~/.cursor/mcp.json, para valer em todos.

Claude Code

claude mcp add --transport stdio fiscal-brasil -- uvx mcp-fiscal-brasil

VS Code + Continue

Crie o arquivo .continue/mcpServers/fiscal-brasil.yaml no seu projeto (o MCP funciona no modo agente):

name: Fiscal Brasil
version: 0.0.1
schema: v1
mcpServers:
  - name: fiscal-brasil
    command: uvx
    args:
      - mcp-fiscal-brasil

Ou adicione só o bloco mcpServers ao seu ~/.continue/config.yaml.

Outros clientes MCP

Qualquer cliente com transporte stdio funciona com o comando uvx e o argumento mcp-fiscal-brasil. O servidor também está no registry oficial do MCP como io.github.DeHor-Labs/mcp-fiscal-brasil.

Instalação permanente com pip

pip install mcp-fiscal-brasil

Depois disso, use "command": "mcp-fiscal-brasil" (sem args) na configuração. O mesmo pacote traz a CLI mcp-fiscal e a API REST mcp-fiscal-api. Guia completo na documentação.

Perguntas frequentes

Inclusive sobre o que o projeto ainda não faz.

Quanto custa?

Nada. O projeto é open source sob licença MIT e todas as ferramentas funcionam com fontes públicas gratuitas, sem cadastro. Existe um provedor premium opcional (cpfcnpj.com.br), desligado por padrão: só é usado se você configurar o seu próprio token, e a cobrança é feita por esse provedor.

Preciso de chave de API ou de certificado digital?

Chave de API, não. Certificado A1 (.pfx/.p12) só é necessário para três ferramentas que falam direto com a SEFAZ por mTLS: consultar_status_sefaz, baixar_nfe_distribuicao e manifestar_nfe. O certificado e a senha ficam na sua máquina e a assinatura é feita localmente.

Para onde vão os meus dados?

O servidor roda localmente no seu computador. Arquivos como XML de NF-e e SPED são processados ali mesmo, sem upload para servidor do projeto. Consultas de CNPJ, CEP e indicadores vão direto às fontes públicas (BrasilAPI, ReceitaWS, Banco Central, IBGE). Lembre que o assistente de IA que você usa recebe as respostas das ferramentas para montar a resposta, então vale a política de privacidade dele.

Quais são as limitações hoje?
  • Não emite NF-e nem NFS-e. Lê, valida, gera DANFE, baixa documentos e manifesta o destinatário.
  • NFS-e e certidões (CND federal e CRF do FGTS) são ferramentas de orientação: indicam o portal e o caminho, não trazem o documento.
  • CT-e: só a validação da chave de acesso (modelo 57). Leitura de XML e consulta de CT-e ainda não existem.
  • A busca de CNPJ por nome é experimental, porque a Receita não oferece essa busca em API pública.
  • Consultas on-line dependem da disponibilidade das fontes públicas, que podem ficar lentas ou fora do ar. A consulta de NF-e/NFC-e pela chave sem o provedor premium pode trazer dados parciais.
  • Simulações (Reforma Tributária, regimes, importação) são estimativas de apoio e não substituem a análise de um contador.
  • O projeto está em versão beta (0.x): nomes e formatos de retorno ainda podem mudar.
Funciona com quais assistentes?

Com qualquer cliente compatível com o Model Context Protocol via stdio, como Claude Desktop, Claude Code, Cursor e VS Code com Continue. Também dá para usar sem assistente nenhum, pela CLI, pelo SDK Python ou pela API REST.
